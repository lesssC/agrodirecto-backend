# P4-06 — Guion de demo y presentación (MUST)

**Rama** `docs/P4-06-demo` · **PR y merge** lun 30 · **Ensayos** mar 1 dic ×2 · **Dueño** P4, con todo el equipo

## Objetivo
Una demo de ~10 minutos, ensayada, con plan B, que muestre el valor para el agricultor.

## Guion (ajustar tiempos al ensayo)
1. **Problema y enfoque (1 min):** agricultor pobre, intermediarios, precio justo sin regateo, comisión la paga el comprador, funciona sin computadora.
2. **Agente de campo (2 min):** registra y verifica a un agricultor; publica su producto con foto; el agricultor recibe aviso (SMS/WhatsApp).
3. **Comprador (2 min):** catálogo, precio justo, carrito, checkout, pago (retenido).
4. **Agricultor (1 min):** acepta el pedido, ve notificación en vivo, marca entrega.
5. **Confianza (2 min):** comprador confirma y reseña; segundo pedido con disputa por daño en transporte; descargo; admin resuelve.
6. **Admin y seguridad (1 min):** resumen, auditoría, 2FA, precios de referencia.
7. **Arquitectura y cierre (1 min):** Spring Boot + MySQL + React, CI, despliegue, trabajo futuro (pago real, logística).

## Entregables
- Datos semilla verificados (cuentas demo, productos con foto, un pedido listo en cada estado).
- Capturas en `docs/screenshots/` y README final de ambos repos.
- **Video de respaldo** grabado el lun 30 con todo el flujo.
- Plan B: si la API no despierta, usar el video; si falla un proveedor externo, usar el modo simulado rotulado.

## Criterios de aceptación
- Dos ensayos completos el mar 1 sin interrupciones y bajo 12 minutos.
- Cada integrante sabe qué rol narra y qué cuenta usa (admin, agricultor, comprador, agente).
- 10 minutos antes: `GET /actuator/health` y navegar la web para calentar.
