# P2-02 — Recuperación de contraseña por correo (MUST, desbloquea P3-05)

**Rama** `feat/P2-02-recuperar-contrasena` · **PR y merge** vie 27 · **Dueño** P2

## Objetivo
Que un usuario que olvidó su contraseña pueda restablecerla con un enlace enviado por correo.

## Contexto
No existe envío de correo ni recuperación (`usuarios/**`, `AuthController.java:30-41`). JWT dura 12 h y no se revoca. El frontend hoy solo muestra un aviso (`Login.tsx:170`).

## Contrato
Ver `contratos.md` → Recuperación de contraseña.

## Cambios
1. Migración **V11** `token_usuario(id, usuario_id, tipo, token_hash, expira_en, usado_en, creado_en)`; tipo `RESTABLECER`.
2. Interfaz `EnvioCorreo` + implementación SMTP/API (Resend o Brevo free) y `EnvioCorreoSimulado` (log) para tests/dev. Selección por `correo.proveedor`. Variables: `CORREO_API_KEY`, `CORREO_REMITENTE`, `FRONTEND_URL`.
3. `POST /api/auth/olvide-contrasena`: genera token aleatorio (≥ 32 bytes), guarda solo su hash, expira en 30 min, invalida tokens anteriores; responde 202 siempre y sin revelar si el correo existe (mismo tiempo de respuesta aproximado).
4. `POST /api/auth/restablecer`: valida token (existe, no usado, no expirado), aplica política de contraseña (8–72, rechazar lista corta de contraseñas comunes), guarda hash, marca token usado y registra `contrasena_cambiada_en`; los JWT con `iat` anterior dejan de ser válidos (comprobarlo en el filtro JWT).
5. Plantilla de correo en español, texto plano + HTML simple, enlace `${FRONTEND_URL}/#restablecer?token=…`.
6. Rate limit lo aporta P1-02.

## Criterios de aceptación
- Dado correo existente → 202 y se "envía" un correo con token; dado inexistente → 202 sin correo.
- Dado token válido → 204, la contraseña vieja ya no sirve y la nueva sí; el mismo token por segunda vez → 400 `TOKEN_INVALIDO`.
- Dado token expirado → 400. Dado un JWT emitido antes del cambio → 401.

## Tests
`RecuperarContrasenaTest` (feliz, expirado, reutilizado, inexistente, invalidación de JWT, contraseña débil).

## Fuera de alcance
Verificación de correo al registrarse (COULD), 2FA por correo.

## Verificar
`./mvnw test`; con proveedor real, recibir el correo en un buzón de prueba.
