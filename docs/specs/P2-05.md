# P2-05 — Documentación Swagger (COULD)

**Rama** `docs/P2-05-swagger` · **PR y merge** sáb 28 · **Dueño** P2

## Objetivo
Que `/swagger-ui.html` sea útil para explicar la API en la presentación.

## Contexto
`config/OpenApiConfig.java` define el esquema JWT; hay 0 anotaciones `@Tag`/`@Operation`. `DocumentacionApiTest` ya verifica que `/v3/api-docs` responde. En producción Swagger puede estar apagado (P1-01).

## Cambios
1. `@Tag(name=…, description=…)` por controller (Auth, Productores, Catálogo, Pedidos, Confianza, Admin, Notificaciones, Archivos, Pagos).
2. `@Operation(summary=…)` y `@ApiResponse` para los códigos de error de reglas de negocio más importantes (ej. `regla` en pedidos y pagos).
3. Agrupar endpoints públicos vs autenticados; documentar el formato `ApiError`.

## Criterios de aceptación
- `/v3/api-docs` lista tags con descripción y cada operación tiene resumen.
- `DocumentacionApiTest` verde.

## Fuera de alcance
Generar cliente automáticamente.

## Verificar
`./mvnw test`; abrir Swagger local.
