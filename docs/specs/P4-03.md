# P4-03 — Pruebas E2E del backend (MUST)

**Rama** `test/P4-03-e2e-backend` · **PR** vie 27 · **Merge** sáb 28 · **Dueño** P4

## Objetivo
Un test que recorra el flujo completo del negocio de principio a fin, y cubrir los cálculos críticos.

## Contexto
`src/test/java/**` (≈95 tests, H2 modo MySQL, MockMvc). Existen piezas sueltas (`PagoRetenidoTest`, `ConfianzaTest`) pero no un flujo continuo. Sin tests unitarios de `CalculadoraPedido`, `Dinero`, `CifradoSecretos`.

## Cambios
1. `FlujoCompletoTest`: registrar productor y comprador → productor crea producto → comprador cotiza y crea pedido → paga (pasarela simulada/falsa) → productor acepta → marca entregado → comprador confirma recepción → deja reseña → reputación actualizada.
2. `FlujoDisputaTest`: igual hasta entregado → comprador abre disputa con evidencia → productor presenta descargo → admin resuelve (ambas ramas) → pago liberado/reembolsado.
3. Unitarios: `CalculadoraPedidoTest` (comisión a cargo del comprador, 100% al agricultor, redondeos), `DineroTest`, `CifradoSecretosTest`.
4. (COULD) Test de concurrencia de stock con dos compradores simultáneos; Testcontainers MySQL para validar migraciones; JaCoCo.

## Criterios de aceptación
- Ambos flujos pasan en `./mvnw test` y fallan si se rompe una regla clave (verificar rompiéndola localmente).
- Los cálculos de dinero están cubiertos con casos límite (cantidades decimales, tarifa mínima).

## Fuera de alcance
Tests de carga.

## Verificar
`./mvnw test` (vía Docker).
