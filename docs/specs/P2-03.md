# P2-03 — CRUD de categorías (admin) (SHOULD)

**Rama** `feat/P2-03-categorias-admin` · **PR** vie 27 · **Merge** sáb 28 · **Dueño** P2

## Objetivo
Que el administrador gestione categorías sin tocar la base de datos.

## Contexto
`catalogo/web/CatalogoController.java:20-38` solo expone `GET /api/categorias`. Los precios de referencia ya se gestionan en `/api/admin/precios-referencia` (`AdminController`). Migraciones: no se requieren salvo unicidad de nombre (V12 si hace falta).

## Contrato
`contratos.md` → Categorías admin.

## Cambios
1. Endpoints `GET/POST/PUT/DELETE /api/admin/categorias`.
2. Nombre único (insensible a mayúsculas), 2–60 caracteres.
3. `DELETE` → 409 `CATEGORIA_EN_USO` si hay productos o precios de referencia asociados.
4. Registrar altas/cambios/bajas en auditoría (V7).

## Criterios de aceptación
- Crear, listar, renombrar y borrar una categoría sin productos funciona.
- Duplicado → 409 `CATEGORIA_DUPLICADA`; borrar con productos → 409 `CATEGORIA_EN_USO`.
- Usuario no admin → 403. El `GET /api/categorias` público refleja los cambios.

## Tests
`CategoriaAdminTest`.

## Fuera de alcance
Jerarquía de categorías, imágenes de categoría.

## Verificar
`./mvnw test`.
